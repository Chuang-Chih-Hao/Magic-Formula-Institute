# 🎪 魔法配方研究所 4.2｜魔法事件大特效與策略分工

國小六年級「比、比值與比例應用」的多人 2D 經營遊戲。最多四名學生設計不同的飲料攤位，先答題選三款調飲（也可選一款高風險自由調配）並鎖定，之後觀看動物 NPC 在同一張地圖自由比較店家、決定是否購買。**約每十分鐘可以重新調整商品與策略。**

[遊戲網站](https://magic-formula-institute.onrender.com)｜[GitHub 程式庫](https://github.com/Chuang-Chih-Hao/Magic-Formula-Institute)｜[Render 控制台](https://dashboard.render.com/web/srv-dbu40qtckfvc73b1m58g)

## 1. 第一次進入沒有任何預設飲料

- 新加入的學生從 **0 款已解鎖、0 款已選** 開始；第一輪準備限時 6 分鐘，不能在完全不解題的情況下開店。
- 共有 **12 款一般飲料＋3 款傳說級特殊食譜**：🍓 莓果初戀、🌙 月光蘇打、🌿 森林薄荷、🍑 蜜桃星星、🫐 紫晶夢境、🌈 彩虹晨露、🍫 可可星河、❄️ 雪花氣泡、🍯 日光蜂蜜、☁️ 銀河奶霜、🌹 玫瑰泡泡、🍋 綠野檸香。
- 一般飲品**第一題答對會解鎖**；再額外答對相同飲品的進化題，品質每級 **+5 分**，最多進化到 **Lv.3**，最高品質 **115 分**；高品質加成會進入 NPC 的購買比較分數。
- 玩家要賣三款不同飲品；若使用一款自由調配，只需再解鎖兩款普通飲品，在菜單挑三款，各自調整材料比例和售價，選建築及兩件裝飾，然後鎖定。
- **14 種比例題型結構**，題目會替換情境、材料、數字和敘述，並嘗試避開最近重複題目；答錯顯示解析，不扣現有營收。

## 2. 新增「🧪 自由調配實驗飲」

在**三款招牌飲品的下拉選單**，除了已解鎖的正常配方，還可直接選擇「🧪 自由調配實驗飲」。這款飲料不需要先完成固定食譜，但**每輪最多只能販售一款自由調配**；其餘兩款需要靠數學題解鎖，避免繞過課堂解題。

學生可以自行輸入花露、星糖、月光水的用量（每項 1～12 匙、總量最多 27 匙）及定價（12～80 金幣）。沒有「完美比例」可背誦，也不會因為猜對某一組特定材料就保證高品質。口味依用量最多的材料決定：花露為甜美、星糖為夢幻、月光水為清爽（同量依此順序判定）。

**品質由伺服器在按「鎖定攤位」時一次抽定：**

| 抽中機率 | 品質區間 | 風險 |
|---|---|---|
| **70%** | 20～59 分 | 大多不理想 |
| **25%** | 60～84 分 | 普通 |
| **5%** | 85～110 分 | 少數會出現優質飲料 |

自由調配可以先儲存原料及售價，但**鎖定之前看不到品質**，而且儲存、修改或重新整理網頁都不能預先抽品質。每輪一旦鎖定，品質就固定並直接進入 NPC 的跨店評分；本輪不能重抽。下一輪若主動重選、鎖定自由調配，才會重新抽一次；若未完成鎖定而由系統沿用上一輪菜單，則沿用上輪品質，不會白白獲得重抽機會。

這個機制的教學重點是**機率、風險、品質與售價的權衡**：學生要思考是否值得使用高風險的自由調配，還是選擇已經解鎖、進化且品質穩定的飲品。

## 3. 一輪十分鐘、持續循環

| 階段 | 第一次 | 第二輪開始 |
|---|---|---|
| 準備 | **6 分鐘**，先解鎖三款並完成開店 | 預設 **6 分鐘**，可換三款商品、調飲比例、價格與裝飾 |
| 鎖定 | 全員完成可由**老師提前開市**；6 分鐘到時自動為尚未完成的學生補齊三款基本飲料並開市，補齊不算答題成績 | 所有人鎖定就**自動開市**；逾時未鎖定時強制沿用上一輪最後已儲存菜單 |
| 動物購買 | 預設 **4 分鐘**，期間設定完全鎖定 | 預設 **4 分鐘**，同樣禁止改店 |
| 結束 | 記錄淨利及售出杯數 | 自動顯示上一輪的新增淨利，進入下一輪調整 |

老師可在第一輪將每輪販售時間改成 **3、4 或 5 分鐘**；後續準備期會對應為 7、6 或 5 分鐘，以維持每輪約十分鐘。老師仍能暫停、繼續、提前結束整場或重開。參加人數 1～4 位都可以進行。

**第一輪也有 6 分鐘的準備期限。** 房間建立後，第一位學生加入時開始計算整場 30 分鐘；老師可提前宣布開市。第一輪逾時尚未完成的學生，會由系統臨時補足三款基本飲料和裝飾（不列為答對、不提供進化等級），避免卡住全班。第二輪起保留已解鎖配方、進化等級及累積淨利，未鎖定者沿用已儲存菜單。**全場滿 30 分鐘立即強制結算**，包含準備期、販售期及暫停期間，任何人都不能延長倒數。

## 4. 傳說秘方：掉落後還要破解高難度題

所有學生一開始都沒有傳說食譜。一般比例題答對時，每次有 **16% 機率**掉落尚未取得的特殊食譜線索；營業時也有機會發生「📜 天降傳說卷軸」事件，將線索送給其中一間攤位，讓該學生在下一輪準備期挑戰。

| 傳說飲品 | 口味 | 品質優勢 |
|---|---|---|
| 🌌 極光精靈露 | 夢幻 | 基本品質額外 +8 |
| 🔥 鳳凰焰火茶 | 甜美 | 基本品質額外 +8 |
| ☄️ 彗星冰晶汽水 | 清爽 | 基本品質額外 +8 |

得到線索後，研究桌會出現**釘在可捲動欄位頂端的金紫色大型魔法卷軸卡片**，有浮動卷軸、星光、特別大的「立即挑戰」按鈕；學生的頂部狀態列也會顯示「📜 傳說卷軸待解！」，按下可以回到卷軸卡片，避免錯過。

得到線索**不等於直接得到配方**：必須完成專屬的多步驟高難度比例題，涵蓋連續分配、加入原料後約分、比例與成本連算及分數占比等。**答錯線索消失，下次仍有機會掉落；題目開始後不可換題重抽。** 成功解鎖的傳說飲品永久保留於該場，仍可進化至 Lv.3，完美比例最高品質 123 分。

## 5. 園遊會隨機事件與玩家經營行動

**每輪 4 分鐘販售期**，伺服器每約 **28～42 秒**觸發一種事件。全部玩家同步看到**大型黃色／紫色閃光事件橫幅、事件名稱、影響攤位、實際獎懲、剩餘秒數**；2D 地圖則會播放持續動畫，不再只有小圖示：流星拖尾與大量閃光、大片翻滾濃霧、金幣雨、動物旅行隊伍、氣球彩帶遊行，以及巨大卷軸降落與星星環繞。攤位前還會閃爍受影響的加減分數。

| 隨機事件 | 實際影響 |
|---|---|
| 🌠 流星糖粉雨 | 隨機一間店 30 秒內吸引力 +22 |
| 🌫️ 迷霧小搗蛋 | 一間店 30 秒內吸引力 -23；防護罩可抵擋 |
| 🎟️ 金色幸運券 | 一間店獲得 8～16 金幣獎金，計入淨利而非飲品銷量 |
| 🐾 動物旅行團 | 30 秒內 NPC 出現更頻繁 |
| 🎈 口味遊行 | 30 秒內新 NPC 特別偏好甜美、清爽或夢幻口味之一 |
| 📜 天降傳說卷軸 | 一位學生獲得挑戰傳說食譜的線索（下輪可解題） |

學生在販售階段不只能觀看地圖，還可自由決定是否花費**已賺得的淨利**採取以下策略。行動每次有 22 秒冷卻時間，由伺服器確實扣款。**招攬人潮**與**提高成交率**是兩個不同機制，不再只是對同一個評分加不同分數。地圖上分別有擴散的喇叭聲波與顧客隊伍，以及閃光的試飲杯；策略面板會即時統計招來的人次和試喝期間成交杯數。

| 經營行動 | 花費 | 真正作用 |
|---|---:|---|
| 📣 魔法招牌攬客 | 18 金幣 | **60 秒內每約 4～5 秒多出一位 NPC**，先到你的店看商品，再自由比較是否購買；不直接改變商品評分 |
| 🥤 開放試喝 | 12 金幣 | **60 秒內選擇這間店的 NPC 購買機率最高 +22 個百分點**，人數不增加，售出才計數 |
| 🛡️ 星光防護罩 | 15 金幣 | 90 秒內可抵擋一次迷霧事件 |

攬客不保證銷售，仍需考慮顧客預算和商品品質；試喝能提高成交率，也不保證每一位都購買。每輪有數量統計，方便教師讓學生比較「增加訪客」和「提高成交」哪個更划算。免費事件不收金幣；花費及幸運獎金都會被計入淨利。

## 6. 有作用的 2D 裝飾與購物評分

建築：🍓 草莓糖果屋、🔮 紫晶星光塔、🌿 森林玻璃屋、🍑 蜜桃茶亭；造型不只更換顏色。每間攤位可選兩個裝飾：

| 裝飾 | 在地圖上的樣子 | NPC 加成 |
|---|---|---|
| 🎡 巨型風車招牌 | 實際旋轉的大型風車 | 所有口味 +16 |
| 🌷 蜜糖花圃 | 一排盛開花朵 | 甜美顧客 +25 |
| ⛲ 薄荷水泉 | 水池與噴泉水花 | 清爽顧客 +25 |
| ⭐ 星光小舞台 | 星星和燈光 | 夢幻顧客 +25 |
| 🥤 試飲小桌 | 有試喝飲料的木桌 | 所有口味 +12 |

NPC 會步行瀏覽不同攤位，綜合**品質（含進化）、售價與自身預算、喜好口味、裝潢**比較所有店家的商品。每名 NPC 只會選一間購買或決定不買，販售期間無法改價或修改裝飾。點動物可看比較分數；點攤位可看三款飲品品質與價格；右方日記顯示實際成交原因。

選取地圖中的 NPC 後，**三段選取弧線會跟著角色移動**，虛線追蹤角色到下一個目的地，不能固定在角色剛進場的位置。NPC 在**道路上完全不透明**，只有靠近商店櫃檯時才呈半透明，避免擋住販售的飲品。

NPC 在地圖上的模樣直接使用與右側「顧客正在比較什麼？」相同的動物表情圖示（兔、貓、熊、狐狸、鹿），避免角色外觀不一致。氣泡不再重複「在逛攤比價」：會依沿途觀察、不同招牌、口味和價格輪換台詞。**未成交會依真正原因**（超過預算、品質低、價格偏高、口味不合、還不夠心動）改變台詞。Gemini API 產生台詞時也會收到原因及購買狀態，不會把「沒買」講成「已買」。

## 7. UI 完整等比例縮放，不換位置

**所有畫面統一使用 1600 × 1000 虛擬座標**。根據實際瀏覽器大小，只會整體縮放、置中，不會把三欄改成上下排列。準備期更換配方、解題、進化時保留各欄原捲動位置，其他學生同步更新也不再強制關閉正在操作的選單。**營業期可直接在地圖上使用滑鼠滾輪，將整個市場頁面向下捲動**，以查看下方的攤位詳情、排行榜和顧客日記。為保留完整位置，手機建議橫向使用，直向手機上的字會較小。

## 8. Gemini 與隱私

既有 Render Environment 的 **GEMINI_API_KEY** 以及 **AI_NPC_ENABLED=true** 設定保留。可用 **GEMINI_MODEL** 指定模型，預設 Gemini 3.5 Flash-Lite。每個房間最密約每 45 秒發出一次 AI 對話請求；失敗時退回內建台詞，購買與成績不受影響。**不要將金鑰放到 GitHub、瀏覽器或聊天中；只傳虛構 NPC 的交易情境，不傳學生個資。**

[健康檢查](https://magic-formula-institute.onrender.com/health) 的 npcAiMode 欄位可看有無辨識金鑰；但這不代表每次外部 AI 呼叫都會成功。

## 9. 技術與上課建議

- fair-server.js：教師房間、第一輪 6 分鐘準備、每輪自動鎖定／販售／成績、跨店購買、傳說配方掉落、消費與六種市場隨機事件。
- fair-questions.js：14 種一般比例題型、4 類多步驟傳說難題與近期避重。
- public/fair.js、public/fair.css：固定座標畫面、原創 Canvas 2D 園遊會、動物行走、巨大動態事件特效、傳說卷軸高亮卡片、兩種不同的營業策略面板。
- server.js：Gemini 伺服器端請求與備援。
- test/fair-v2.test.js、test/gemini.test.js：比值、15 款固定配方、自由調配品質抽選、稀有掉落／特殊挑戰、**加碼訪客與提高成交率的不同效果**、6 種市場事件、多人房間、輪替結算及 Gemini 測試。
- test/browser-smoke.js：Chromium 真正瀏覽器驗收：解鎖三款、自由調配與品質揭曉、等比畫面、鎖定、開市與 NPC 交易。
- GitHub Actions 自動測試；Render Node.js Web Service 自動部署，Health Check Path 為 /health。

本機 Node.js 20+：執行 npm install、npm test、npm start 後開啟 http://localhost:3000 。

**注意：** 房間、成績目前放在 Render 單一執行個體的記憶體中。Render Free 休眠／重啟、服務重新部署會清除當前房間。正式上課時不要中途更新程式。

40＋10＋40 分鐘可安排：第一節解題解鎖／進化與攤位設計，第二節進行多輪 10 分鐘園遊會，每輪討論價格、品質、裝潢與顧客偏好造成的結果。
