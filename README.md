# 🎪 魔法配方研究所 3.0｜多回合動物園遊會

國小六年級「比、比值與比例應用」的多人 2D 經營遊戲。最多四名學生設計不同的飲料攤位，先答題選三款調飲並鎖定，之後觀看動物 NPC 在同一張地圖自由比較店家、決定是否購買。**約每十分鐘可以重新調整商品與策略。**

[遊戲網站](https://magic-formula-institute.onrender.com)｜[GitHub 程式庫](https://github.com/Chuang-Chih-Hao/Magic-Formula-Institute)｜[Render 控制台](https://dashboard.render.com/web/srv-dbu40qtckfvc73b1m58g)

## 1. 第一次進入沒有任何預設飲料

- 新加入的學生從 **0 款已解鎖、0 款已選** 開始；第一輪準備限時 6 分鐘，不能在完全不解題的情況下開店。
- 共有 **12 款飲料**：🍓 莓果初戀、🌙 月光蘇打、🌿 森林薄荷、🍑 蜜桃星星、🫐 紫晶夢境、🌈 彩虹晨露、🍫 可可星河、❄️ 雪花氣泡、🍯 日光蜂蜜、☁️ 銀河奶霜、🌹 玫瑰泡泡、🍋 綠野檸香。
- 每款飲品**第一題答對會解鎖**；再額外答對相同飲品的進化題，品質每級 **+5 分**，最多進化到 **Lv.3**，最高品質 **115 分**；高品質加成會進入 NPC 的購買比較分數。
- 玩家必須至少解鎖三款不同飲品，在菜單挑三款，各自調整材料比例和售價，選建築及兩件裝飾，然後鎖定。
- **14 種比例題型結構**，題目會替換情境、材料、數字和敘述，並嘗試避開最近重複題目；答錯顯示解析，不扣現有營收。

## 2. 一輪十分鐘、持續循環

| 階段 | 第一次 | 第二輪開始 |
|---|---|---|
| 準備 | **6 分鐘**，先解鎖三款並完成開店 | 預設 **6 分鐘**，可換三款商品、調飲比例、價格與裝飾 |
| 鎖定 | 全員完成可由**老師提前開市**；6 分鐘到時自動為尚未完成的學生補齊三款基本飲料並開市，補齊不算答題成績 | 所有人鎖定就**自動開市**；逾時未鎖定時強制沿用上一輪最後已儲存菜單 |
| 動物購買 | 預設 **4 分鐘**，期間設定完全鎖定 | 預設 **4 分鐘**，同樣禁止改店 |
| 結束 | 記錄淨利及售出杯數 | 自動顯示上一輪的新增淨利，進入下一輪調整 |

老師可在第一輪將每輪販售時間改成 **3、4 或 5 分鐘**；後續準備期會對應為 7、6 或 5 分鐘，以維持每輪約十分鐘。老師仍能暫停、繼續、提前結束整場或重開。參加人數 1～4 位都可以進行。

**第一輪也有 6 分鐘的準備期限。** 房間建立後，第一位學生加入時開始計算整場 30 分鐘；老師可提前宣布開市。第一輪逾時尚未完成的學生，會由系統臨時補足三款基本飲料和裝飾（不列為答對、不提供進化等級），避免卡住全班。第二輪起保留已解鎖配方、進化等級及累積淨利，未鎖定者沿用已儲存菜單。**全場滿 30 分鐘立即強制結算**，包含準備期、販售期及暫停期間，任何人都不能延長倒數。

## 3. 有作用的 2D 裝飾與購物評分

建築：🍓 草莓糖果屋、🔮 紫晶星光塔、🌿 森林玻璃屋、🍑 蜜桃茶亭；造型不只更換顏色。每間攤位可選兩個裝飾：

| 裝飾 | 在地圖上的樣子 | NPC 加成 |
|---|---|---|
| 🎡 巨型風車招牌 | 實際旋轉的大型風車 | 所有口味 +16 |
| 🌷 蜜糖花圃 | 一排盛開花朵 | 甜美顧客 +25 |
| ⛲ 薄荷水泉 | 水池與噴泉水花 | 清爽顧客 +25 |
| ⭐ 星光小舞台 | 星星和燈光 | 夢幻顧客 +25 |
| 🥤 試飲小桌 | 有試喝飲料的木桌 | 所有口味 +12 |

NPC 會步行瀏覽不同攤位，綜合**品質（含進化）、售價與自身預算、喜好口味、裝潢**比較所有店家的商品。每名 NPC 只會選一間購買或決定不買，販售期間無法改價或修改裝飾。點動物可看比較分數；點攤位可看三款飲品品質與價格；右方日記顯示實際成交原因。

NPC 在地圖上的模樣直接使用與右側「顧客正在比較什麼？」相同的動物表情圖示（兔、貓、熊、狐狸、鹿），避免角色外觀不一致。氣泡不再重複「在逛攤比價」：會依沿途觀察、不同招牌、口味和價格輪換台詞。**未成交會依真正原因**（超過預算、品質低、價格偏高、口味不合、還不夠心動）改變台詞。Gemini API 產生台詞時也會收到原因及購買狀態，不會把「沒買」講成「已買」。

## 4. UI 完整等比例縮放，不換位置

**所有畫面統一使用 1600 × 1000 虛擬座標**。根據實際瀏覽器大小，只會整體縮放、置中，不會把三欄改成上下排列。準備期更換配方、解題、進化時保留各欄原捲動位置，其他學生同步更新也不再強制關閉正在操作的選單。**營業期可直接在地圖上使用滑鼠滾輪，將整個市場頁面向下捲動**，以查看下方的攤位詳情、排行榜和顧客日記。為保留完整位置，手機建議橫向使用，直向手機上的字會較小。

## 5. Gemini 與隱私

既有 Render Environment 的 **GEMINI_API_KEY** 以及 **AI_NPC_ENABLED=true** 設定保留。可用 **GEMINI_MODEL** 指定模型，預設 Gemini 3.5 Flash-Lite。每個房間最密約每 45 秒發出一次 AI 對話請求；失敗時退回內建台詞，購買與成績不受影響。**不要將金鑰放到 GitHub、瀏覽器或聊天中；只傳虛構 NPC 的交易情境，不傳學生個資。**

[健康檢查](https://magic-formula-institute.onrender.com/health) 的 npcAiMode 欄位可看有無辨識金鑰；但這不代表每次外部 AI 呼叫都會成功。

## 6. 技術與上課建議

- fair-server.js：教師房間、第一輪無限準備、每輪自動鎖定／販售／成績、跨店購買、配方進化。
- fair-questions.js：14 種比例題型與近期避重。
- public/fair.js、public/fair.css：固定座標畫面、原創 Canvas 2D 園遊會、動物行走、裝飾與對話。
- server.js：Gemini 伺服器端請求與備援。
- test/fair-v2.test.js、test/gemini.test.js：比值、12 配方、進化、跨店比較、四人房間、每輪自動重開及 Gemini 測試。
- test/browser-smoke.js：Chromium 真正瀏覽器驗收：解鎖三款、配置、等比畫面、鎖定、開市與 NPC 交易。
- GitHub Actions 自動測試；Render Node.js Web Service 自動部署，Health Check Path 為 /health。

本機 Node.js 20+：執行 npm install、npm test、npm start 後開啟 http://localhost:3000 。

**注意：** 房間、成績目前放在 Render 單一執行個體的記憶體中。Render Free 休眠／重啟、服務重新部署會清除當前房間。正式上課時不要中途更新程式。

40＋10＋40 分鐘可安排：第一節解題解鎖／進化與攤位設計，第二節進行多輪 10 分鐘園遊會，每輪討論價格、品質、裝潢與顧客偏好造成的結果。
